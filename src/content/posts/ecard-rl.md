## 1. 项目简介
皇帝牌（E-card）是一个两人零和博弈，双方各持一张王牌和四张平民牌，每轮同时出牌，平局则进入下一轮。这个游戏虽然规则简单，却蕴含了不完全信息下的序贯决策（每轮同时行动，平局才继续），其混合策略纳什均衡可以通过逆向归纳精确求解。

本项目利用**自博弈强化学习**（两个 AI 互相对弈学习）来研究“皇帝牌”这个纸牌游戏中，三样东西的差异：
- **数学上的完美理性策略**（博弈论算出来的最优解）；
- **AI 在实际学习中会停靠的地方**（强化学习算法自然形成的习惯）；
- **引入“赌徒心理”后**（例如害怕损失、高估小概率等），AI 的习惯会怎样变化。

简单说，**不是让 AI 打赢游戏，而是用 AI 来观察“人”可能怎样偏离理性**。

## 2. 游戏规则（皇帝牌）

这是一款双人零和纸牌游戏，一人扮演“皇帝”，另一人扮演“奴隶”。

- **牌型**：每人各有 1 张“王牌”（A）和 4 张“平民牌”（C）。
- **对局**：双方同时亮出一张牌，共进行最多 5 轮。
- **胜负判定**（从皇帝视角）：
  - 皇帝出 A，奴隶出 A → 奴隶胜，皇帝得 **-5** 分。
  - 皇帝出 A，奴隶出 C → 皇帝胜，皇帝得 **+1** 分。
  - 皇帝出 C，奴隶出 A → 皇帝胜，皇帝得 **+1** 分。
  - 皇帝出 C，奴隶出 C → **平局**，进入下一轮（双方各消耗一张平民牌）。
- **强制结束**：如果前 4 轮全是平局，第 5 轮双方只剩王牌，不得不都出 A，此时奴隶获胜（皇帝 -5）。

> 游戏的关键：越到后期，平局的代价越大（因为最后必输），所以双方会越来越倾向于出王牌。

## 3. 核心术语通俗解释

| 术语 | 通俗解释 |
| :--- | :--- |
| **理性均衡（Nash 均衡）** | 如果双方都是绝对聪明且不犯错的玩家，他们最终会采取一种“混合策略”——即用一定的概率出 A 或 C，使得任何一方单独改变策略都不会占便宜。数学上可以精确算出这个概率。 |
| **自博弈（Self-play）** | 让两个 AI 互相作为对手进行训练，而不是与固定对手或环境对抗。就像两个棋手不断互相对弈来提高自己。 |
| **PPO（近端策略优化）** | 一种主流的强化学习算法，用于训练 AI 决策。它通过“试错”和“奖励”来调整策略，并且会限制每次更新的幅度，以防学偏。 |
| **效用（Utility）** | 指 AI 对输赢结果的“感受”或“价值”。默认下，赢 +1 就是 +1，输 -5 就是 -5（客观收益）。但我们可以修改这种感受，例如让输的惩罚更重（损失厌恶），这样 AI 就会改变行为。 |
| **前景理论（Prospect Theory）** | 行为经济学理论，描述人如何实际感知收益和损失。例如，人们对损失的敏感度通常高于同等收益（损失厌恶），并且会扭曲概率判断（高估小概率事件）。我们在 AI 的“效用”中模拟这些偏差。 |
| **熵正则（Entropy Regularization）** | 在强化学习中，为了让 AI 不要过早“顽固”于一种策略，会鼓励它保持一定的随机性。相当于给 AI 的探索行为加分。 |
| **min-ent 正则** | 一种更严格的熵约束，会强制 AI 的策略概率不能低于某个下限，从而保证它永远有探索余地。我们实验中将其强度设为 0.5（默认），但发现这个值会严重影响 AI 的最终行为。 |
| **弱平稳（Weak Stationarity）** | 指 AI 的策略在训练后期不再大幅波动，但并非完全静止（比如小范围震荡）。我们用它来判断 AI 是否“停下来了”。 |
| **优势归一化（Advantage Normalization）** | 一种训练技巧，把 AI 的“优势信号”（该动作比平均好多少）缩放到同一尺度，可防止某些参数（如损失厌恶系数）因数值过大而主导学习。我们实验发现，**开启该技巧后，原本的某些效应会消失**。 |
| **窗口均值 vs 最终 checkpoint** | “窗口均值”是取训练最后一段（如最后 20 万步）策略的平均值，反映稳定趋势；“最终 checkpoint”是训练结束时那一刻的策略，可能因随机波动而偏移。两者有时不一致，需要小心对待。 |
| **q-p 偏差** | 表示奴隶出王牌的概率（q）减去皇帝出王牌的概率（p）。理性均衡下两者相等（均为 0.2），但实验中常见 q > p，即奴隶更倾向于出王牌。寻找这个偏差的来源是本项目的核心之一。 |

## 4. 研究问题

1. **理性均衡是什么？** —— 用数学直接算出游戏的最优策略，作为对比基准。
2. **AI 默认学习会停在哪里？** —— 在不加入任何心理偏差的情况下，PPO 自博弈最终会形成怎样的出牌习惯？
3. **加入心理偏差后，AI 的习惯会怎样移动？** —— 例如，让 AI 更害怕损失（λ 增大），其出牌概率会变化吗？这些变化是否源于心理参数的“尺度效应”，还是真的改变了均衡？

---

## 5. 实验方法链

我们构建了一条完整的研究流水线：

1. **数学求解**（`solver.py`）：用逆向归纳递归计算每一轮的混合均衡，给出精确的理性策略（首轮 p=q=0.2，总胜率 80%）。
2. **强化学习环境**（`env.py`）：实现皇帝牌规则，状态简单（仅剩的平民数），奖励完全客观（+1/-5/0），不混入心理因素。
3. **效用层**（`utility.py`）：在强化学习的奖励上叠加心理扭曲（前景理论参数 λ, α, β, γ，以及概率权重偏移），但注意**不改变环境本身的奖励**，只改变 AI 感知到的价值。
4. **PPO 训练**（`ppo.py` + `train.py`）：双智能体（皇帝和奴隶）各自独立策略网络，使用 PPO 算法进行自博弈训练。
5. **大规模扫描**（`sweep.py`）：遍历 λ（损失厌恶）和 τ（概率权重）的多种组合，每组合运行 5 个随机种子，训练 40 万步，并自动记录收敛状态。
6. **分析与评估**（`analyze.py` + `evaluate.py`）：合并多轮运行，做统计检验，绘制相图，并利用保存的策略做逐层评估（检查每一轮的出牌概率和可被利用性）。

## 6. 核心结论

以下结论按证据强度排列（✅ 已证实，🟡 方向性，❌ 失败/不可用）：

### ✅ 数学事实（铁证）
- **理性均衡**：首轮出王牌概率 p=q=0.2，皇帝胜率 80%，逐轮概率为 1/(剩余平民数+1)。这些已经过严密的数学推导和数值验证。
- **主观均衡不变性**：只要心理偏差是“常数权重”（如固定 λ 值），就不会改变上述理性策略。也就是说，**单纯改变参数并不会产生新的“心理均衡”**，只能让 AI 在训练过程中偏离得更远或更近。

### 🟡 方向性证据（一致但不绝对）
- **默认 PPO 落点**：在 min-ent=0.5 时，AI 通常停在 p≈0.20、q≈0.25，即 q 比 p 高出约 0.05。这个现象在多种消融实验中（如对称收益、相同初始化、共享网络）都存在，说明它不是某个偶然因素造成的。
- **λ 增大会降低 p**：即皇帝越害怕损失，出王牌概率越低。但**当开启优势归一化后，这个效应消失了**，说明它只是梯度大小的副作用，而非真正的策略变化。
- **τ（概率权重）不影响奴隶的 q**：但微弱地影响皇帝的 p（τ 增大，p 略升），原因尚需进一步检验。

### ❌ 失败/待解
- **q-p 偏差的真正来源**：尽管排除了很多可能（曲率、收益大小、初始化、网络结构），但最近发现**训练过程中奴隶和皇帝的更新顺序**可能是关键——当随机打乱更新顺序时，训练结束瞬间的 q-p 几乎归零，但中间窗口仍为正。这提示我们，**偏差可能来自训练末期的“相位漂移”**，而非真正的稳定状态。
- **min-ent 不是中性调节器**：我们原以为 0.5 是一个无害的正则化强度，但实验显示，稍微调高到 0.55 或 0.60，AI 的落点就会大幅偏移（q 升至 0.36~0.41）。因此，所有结论都必须限定在“min-ent=0.5”这个特定设置下。
- **400k 步不是瞬态**：延长训练到 100 万步（run19），结果与 40 万步一致，说明我们观察到的不是短暂的过渡现象。

## 7. 项目文件结构

| :--- | :--- |
| `README.md` | 你现在看的这个文件，项目总入口。 |

| `data/runs/` | 所有正式运行的存档（不在 Git 中，需要本地保留）。 |
| `debug/` | 历史调试日志和审计记录。 |

## 8. 快速开始

```bash
# 1. 验证环境与求解器
python -m pytest test_env.py -q
python solver.py

# 2. 快速训练（10 万步，用于测试）
python train.py --quick

# 3. 运行一个完整网格扫描（可能需要 GPU/数小时）
python sweep.py --steps 400000 --min-ent 0.5

# 4. 分析已有结果
python analyze.py --all

# 5. 评估某个运行目录的逐层策略
python evaluate.py --dir data/runs/run11_identity --swap-eval --save
```
## 9.已知限制
- 随机种子数：大多数结论基于 5 个随机种子，统计上仅能支持“方向性”论断，尚不足以给出确定性的因果结论。

- 超参数固定：所有实验固定 min-ent=0.5，因此结论不适用于其他正则强度。

- 无人类数据：我们尚未进行人类游戏实验，因此“心理效应”目前只是模拟层面的假设。
